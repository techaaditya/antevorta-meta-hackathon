# Meta Global AI Developer Hackathon — Operational Brief

**Source:** participant guide supplied by the participant, read on 27 October 2026. The organizer's live announcements take precedence if the guide changes.

## Problem statements

- **Build for Your World:** bring Meta models into a domain you know firsthand to solve a real problem and free up time/mental space.
- **Push the Frontier:** use Meta models to create a new capability or advance software, robotics, manufacturing, energy, materials, science, or control systems.

**Antevorta recommendation:** Build for Your World.

## Model requirement

The project must incorporate Meta models. The guide names the Muse Spark series, Muse Wonder, Muse Image, Muse Voice Transcribe and SAM 3.1 through Meta Model API, Muse Glimmer and Muse Spark Open open-weight models, and Muse Code as a coding agent.

For this kit, the primary application model is `muse-spark-1.3` using the official base URL. Revalidate model availability in the dashboard and current docs before the final submission. Extra models are optional, not a box-checking exercise.

## Participation and code rules

- Solo participation allowed; teams limited to four.
- Repository must be public.
- Submitted demo must clearly show features, code and functionality built during this hackathon.
- Existing concepts or codebases may be a starting point, but new work must be clearly identified.
- Use only code/data/assets you have rights to.
- The guide explicitly warns against basic RAG applications, simple image analyzers, simple AI education chatbots, AI job application screeners, personality analyzers, medical-advice projects, nutrition coaches, sports analyzers/coaches, political or war projects, among other generic/prohibited patterns.

## Judging process

**Stage 1, pass/fail:** baseline viability, reasonable theme fit, and reasonable use of Meta Model API and/or Meta open-weight models during the hackathon.

**Stage 2, 0–10 per category:**

| Category | Weight | Build response |
|---|---:|---|
| Impact | 30% | Show one real decision and a concrete constraint/unknown that affects what the user should investigate next. |
| Use of Meta AI tooling | 25% | Model-selected tool calling, structured output, multiple real tool results, and a verifiable agent trace. |
| Technical depth & execution | 20% | Deterministic maths, strict schemas, tests, bounded agent loop, failure handling, and provenance. |
| Demo | 25% | A stable, visually clear three-minute end-to-end workflow. |
