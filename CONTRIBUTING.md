# Contributing to Antevorta

This is a hackathon project. Keep changes small, testable and attributable to the work performed during the event.

1. Create a focused branch for a feature or fix.
2. Add or update tests for every changed calculation, schema, tool contract or response validation rule.
3. Never commit `.env`, API keys, personal decision data, or raw provider logs.
4. Keep model calls and deterministic calculations separate.
5. Preserve an accurate contribution log in `docs/CONTRIBUTION_LOG_TEMPLATE.md`.
6. Do not claim that a feature works until you have run it. Do not present synthetic test data as user research or evaluation results.
7. Before submitting, follow `docs/SUBMISSION_CHECKLIST.md` and verify public links in a private/incognito browser session.
